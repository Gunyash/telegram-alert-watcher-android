# Alert Watcher для Android

Android-версия Telegram Alert Watcher. Следит за чатами **Telegram** и каналами
**Mattermost** с алертами. Если пришло сообщение, подходящее под `alert_patterns` (и не
подходящее под `ignore_patterns`), приложение будит красным экраном на весь экран и
громким звуком. Сигнал звучит, пока не нажмёшь **ПОДТВЕРДИТЬ**. Паттерны общие для обоих
мессенджеров. Следить можно за одним из них или за обоими: в «Настройках» есть
переключатели «Следить за Telegram» и «Следить за Mattermost».

**⬇ Скачать последнюю версию:**
[AlertWatcher.apk](https://github.com/Gunyash/telegram-alert-watcher-android/releases/latest/download/AlertWatcher.apk)
(Android 8.0+). Установка — в разделе [«Установка готового APK»](#установка-готового-apk-без-android-studio).

## Чем отличается от версии для ПК

На ПК скрипт сам подключался к Telegram через Telethon (`api_id`, `api_hash`, файл
сессии). На телефоне это не нужно: приложение **читает уведомления официальных
приложений Telegram и Mattermost**, которые уже стоят на телефоне. Отсюда следует:

- не нужны `secrets.json`, `api_id`/`api_hash`, файл `.session`, вход по коду;
- доставку сообщений (в том числе при спящем телефоне) обеспечивают сами мессенджеры;
- чат или канал задаётся **названием**, а не числовым ID. Вместо `list_chats.py` есть
  списки «Замеченные» на вкладке «Настройки»: туда попадает каждый чат Telegram и каждый
  канал Mattermost, из которого пришло уведомление;
- в уведомлении должен быть виден текст сообщения (см. шаги 5 и 5а).

| ПК (Python)                       | Android                                                  |
|-----------------------------------|----------------------------------------------------------|
| `watcher.py` (Telethon)           | `notify/TelegramNotificationListener.kt`                 |
| `alarm.py` (tkinter + pygame)     | `ui/AlarmActivity.kt` + `alarm/AlarmSoundPlayer.kt`      |
| очередь окон (`_alarm_lock`)      | `alarm/AlarmController.kt` (очередь + «Подтвердить все») |
| `config.json`                     | вкладка «Настройки» (можно импортировать `config.json` с ПК) |
| `connection_monitor`              | `service/ConnectionMonitor.kt`                           |
| пробел                            | кнопка «ПОДТВЕРДИТЬ» (кнопка «Назад» окно не закрывает)  |
| `python alarm.py` (тест окна)     | «Статус» → «Тестовый алерт»                              |
| вывод в консоль                   | вкладка «Журнал»                                         |

Проверка сообщений работает так же, как на ПК: сначала `ignore_patterns`, потом
`alert_patterns`, регистр не важен. Регулярные выражения из `config.json` работают без
изменений, включая lookahead вида `(?=[\s\S]*...)`.

## Установка готового APK (без Android Studio)

1. Скачайте [AlertWatcher.apk](https://github.com/Gunyash/telegram-alert-watcher-android/releases/latest/download/AlertWatcher.apk)
   прямо на телефон (или скопируйте файл на телефон с компьютера). Все версии — на
   странице **Releases**.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или
   файлового менеджера): разрешите и вернитесь назад.
3. Нажмите «Установить». Если Google Play Защита предупредит о неизвестном приложении,
   нажмите «Подробнее» → «Всё равно установить».
4. Дальше — с **шага 4** ниже. При установке из APK на Android 13+ переключатель
   «Доступ к уведомлениям» будет серым: нажмите в приложении «Сведения о приложении» →
   **⋮** → **«Разрешить ограниченные настройки»**.

> Новые версии ставятся поверх старых, настройки сохраняются. Исключение — если
> приложение было собрано самостоятельно в Android Studio: такая сборка подписана другим
> ключом, и Android не даст поставить APK поверх неё. Тогда сохраните настройки
> («Настройки» → «Экспорт»), удалите приложение, установите APK и импортируйте
> настройки обратно.

## Запуск на телефоне из Android Studio — пошагово

Понадобятся: компьютер с Android Studio (уже установлена), телефон на Android 8 или
новее и USB-кабель, по которому можно передавать данные (не только заряжать).

### Шаг 1. Включить на телефоне режим разработчика и отладку по USB

1. **Настройки → О телефоне** → 7 раз подряд нажмите на **«Номер сборки»**. На Xiaomi
   это пункт «Версия MIUI» или «Версия ОС», на Samsung путь такой: «Сведения о ПО» →
   «Номер сборки». Появится сообщение «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков**. На Xiaomi раздел называется
   «Расширенные настройки → Для разработчиков». Включите **«Отладка по USB»**.
   - Только для Xiaomi: там же включите **«Установка через USB»**. Возможно, понадобится
     войти в Mi-аккаунт и вставить SIM-карту.
3. Подключите телефон кабелем к компьютеру. На телефоне появится вопрос
   **«Разрешить отладку по USB?»**: поставьте галочку «Всегда разрешать с этого
   компьютера» и нажмите **«Разрешить»**. Если вместо этого спрашивается режим USB,
   выберите «Передача файлов».

### Шаг 2. Открыть проект в Android Studio

1. Запустите Android Studio → **Open**. Если уже открыт другой проект, то
   **File → Open…**.
2. Выберите папку `Documents\AndroidStudio\AlertWatcher` и нажмите **OK**. Если Studio
   спросит **Trust Project**, ответьте **Trust**.
3. Подождите, пока внизу закончится **Gradle Sync** (полоса прогресса справа внизу).
   При первом открытии Studio скачивает нужные компоненты, это может занять несколько
   минут. Если Studio предложит обновить Gradle или плагин (Upgrade Assistant), откажитесь:
   проект уже собран и проверен на текущих версиях.

### Шаг 3. Установить приложение на телефон

1. Вверху окна Studio, рядом с зелёным треугольником ▶, есть список устройств. Выберите
   в нём свой телефон (его модель). Если телефона нет в списке, проверьте шаг 1.3 и
   попробуйте другой кабель или USB-порт.
2. Проверьте, что слева от списка устройств выбрана конфигурация **app**.
3. Нажмите **▶ Run 'app'** (или Shift+F10). Через 1–2 минуты на телефоне откроется
   **Alert Watcher**.

После этого приложение остаётся на телефоне. Компьютер и кабель для работы больше
не нужны.

### Шаг 4. Выдать разрешения в приложении

На вкладке **«Статус»** есть список «Что нужно разрешить». Пройдите его сверху вниз,
пока везде не станет ✅. Кнопка у каждого пункта открывает нужный экран настроек Android.

1. **Доступ к уведомлениям.** Без него приложение не работает. В открывшемся списке
   включите **Alert Watcher** и подтвердите.
   - Если переключатель серый и написано «Ограниченная настройка», нажмите
     «Сведения о приложении» → **⋮** в правом верхнем углу → **«Разрешить ограниченные
     настройки»**, затем повторите. Это бывает на Android 13+, если приложение ставили
     APK-файлом, а не через Android Studio.
2. **Показ уведомлений**: «Разрешить».
3. **Полноэкранные уведомления** (Android 14+): включите. Без этого красный экран
   не откроется сам на заблокированном телефоне.
4. **Без ограничений батареи**: «Разрешить». Также см. раздел «Xiaomi, Samsung,
   Huawei…» ниже, это важно.
5. **Поверх других приложений** (необязательно): если включить, красный экран откроется
   сразу, даже когда телефоном пользуются. Без этого разрешения в такой момент
   появится всплывающее уведомление, а звук всё равно будет играть.

### Шаг 5. Настроить Telegram

1. В Telegram **не выключайте уведомления** для чата с алертами. Если родной звук
   Telegram мешает, поставьте для этого чата **«Без звука»**: беззвучное уведомление
   приложение тоже видит. А «Выключить уведомления» и «Заглушить» не подходят,
   при них Telegram ничего не показывает.
2. **Настройки Telegram → Уведомления и звуки**: в разделе групп (или каналов, если
   алерты приходят в канал) должен быть включён **«Предпросмотр сообщений»**. Иначе в
   уведомлении будет только «Новое сообщение», и паттерны не сработают.
3. Если на телефоне стоит код-пароль Telegram, уведомления могут приходить со скрытым
   текстом. Тогда проверьте, что текст сообщения в шторке виден.

### Шаг 5а. Настроить Mattermost

Если алерты приходят и в Mattermost (названия пунктов меню могут немного отличаться в
зависимости от версии Mattermost):

1. **Уведомления канала на телефон — обо всех сообщениях.** По умолчанию Mattermost
   присылает на телефон только упоминания и личные сообщения. Откройте канал (например,
   `zabbix`) → название канала вверху → **«Настройки уведомлений»** → **«Мобильные
   уведомления»** → **«Все новые сообщения»**.
2. **Отправлять уведомления на телефон всегда.** Профиль (аватар) → **«Настройки»** →
   **«Уведомления»** → **«Мобильные уведомления»** → «Отправлять, когда я…» →
   **«В сети, отошёл или не в сети»**. Иначе, пока вы в сети на компьютере, на телефон
   ничего не придёт.
3. **В уведомлении должен быть виден текст.** Пришлите в канал тестовое сообщение и
   посмотрите в шторку телефона. Если там только «Новое сообщение от …» без текста,
   значит, так настроен сервер (параметр «Push Notification Contents»). Тогда попросите
   администратора включить полный текст в уведомлениях: без него паттерны проверить
   нечем.
4. Как и в Telegram, **не выключайте** уведомления канала. Звук Mattermost можно
   отключить в настройках Android для приложения Mattermost.

### Шаг 6. Указать чаты и каналы

1. Подождите, пока в чат или канал с алертами придёт любое сообщение. Можно и самому
   написать туда что-нибудь с другого устройства.
2. Вкладка **«Настройки»** → раздел **«Чаты Telegram»** или **«Каналы Mattermost»** →
   «Замеченные» → нажмите на нужный, и он добавится в поле. Можно вписать название и
   вручную: для Telegram — точно как в шапке чата, для Mattermost — как в списке
   каналов (например, `zabbix`; регистр и «~» не важны).
3. Нажмите **«Сохранить»**.

**Только Telegram, только Mattermost или оба.** В начале разделов «Чаты Telegram» и
«Каналы Mattermost» есть переключатели **«Следить за Telegram»** и **«Следить за
Mattermost»**. Выключенный мессенджер не будит, связь с его сервером не проверяется, а
его пункт на вкладке «Статус» становится необязательным. Списки чатов и адреса при этом
сохраняются: включили обратно, и всё работает как прежде. Сообщения, пришедшие, пока
мессенджер был выключен, после включения тревогу не поднимут. Выключить оба сразу
нельзя: для паузы есть переключатель «Слежение включено» на вкладке «Статус».

Паттерны по умолчанию те же, что в `config.json` с ПК. Если у вас свой `config.json`,
передайте его на телефон (например, отправьте себе в «Избранное» в Telegram и сохраните
в «Загрузки»). Затем: «Настройки» → **«Импорт config.json»** → «Сохранить».

### Шаг 7. Проверить

На вкладке **«Статус»**:
- **«Тестовый алерт сейчас»**: должен появиться красный экран со звуком;
- **«Тестовый алерт через 15 с»**: нажмите и сразу заблокируйте телефон кнопкой
  питания. Через 15 секунд экран должен включиться сам, с красным окном и звуком.
  Это главная проверка ночного режима;
- **«Проверить связь с серверами»**: проверяет Telegram и сервер Mattermost (если указан).

На вкладке «Настройки» есть поле **«Проверить текст сообщения»**: вставьте туда
текст алерта и сразу увидите, сработает он или будет проигнорирован.

## Xiaomi, Samsung, Huawei, Honor, Oppo, Vivo, Realme…

Оболочки этих производителей агрессивно закрывают фоновые приложения. Если алерты
приходят с опозданием или не приходят, когда телефон долго лежит:

- **Xiaomi / Redmi / POCO**: Настройки → Приложения → Alert Watcher →
  **Автозапуск: вкл**, **Контроль активности (батарея): «Нет ограничений»**. Также
  в списке недавних приложений потяните карточку Alert Watcher вниз и нажмите 🔒 (закрепить).
- **Samsung**: Настройки → Обслуживание устройства → Батарея → Ограничения в фоновом
  режиме → **«Приложения, которые никогда не переходят в спящий режим»** → добавить
  Alert Watcher (и **Telegram**, **Mattermost** тоже).
- **Huawei / Honor**: Настройки → Батарея → Запуск приложений → Alert Watcher →
  отключить «Автоматическое управление» и включить все три переключателя.
- Для любых телефонов можно посмотреть инструкцию для своей модели на
  https://dontkillmyapp.com

Те же настройки стоит сделать и для **Telegram** и **Mattermost**: если система усыпит
мессенджер, он не покажет уведомление.

## Мониторинг связи (аналог `connection_monitor`)

Работает так же, как на ПК: раз в `check_interval_sec` секунд проверяется, что у
телефона есть интернет и что серверы отвечают за `check_timeout_sec`. После
`fail_threshold` неудачных проверок подряд срабатывает алерт. Если связь так и не
появилась, он повторяется через `realert_interval_sec`.

Проверяются два адреса, у каждого свой счётчик и свой алерт:
- **Telegram** — `check_url`, по умолчанию `https://api.telegram.org`. Алерт
  **«НЕТ СВЯЗИ С TELEGRAM»**.
- **Mattermost** — `mattermost_check_url`, адрес вашего сервера, например
  `https://mattermost.company.ru`. Вписывается вручную на вкладке «Настройки» → «Алерт о
  потере связи»; если приложение уже видело уведомление Mattermost, рядом появится
  кнопка «Подставить сервер из уведомлений». Алерт **«НЕТ СВЯЗИ С MATTERMOST»** —
  например, когда отвалился VPN до корпоративного сервера.

Пустой адрес или выключенный мессенджер («Следить за …») — эту проверку не делать. Любой ответ сервера (даже ошибка входа) считается
«связь есть»; тревога — только если сервер не ответил вовсе.

Отличия от ПК:
- Проверяется доступность серверов Telegram из телефона, а не собственное подключение
  (своего подключения у приложения нет). Если Telegram у вас работает только через
  прокси **внутри** Telegram, эта проверка будет давать ложные тревоги. В таком случае
  укажите другой адрес в `check_url` или выключите мониторинг.
- Если включить авиарежим, сработает алерт о связи. Это ожидаемо.
- В глубоком сне Android (экран выключен, телефон не на зарядке и лежит неподвижно)
  проверки приостанавливаются до пробуждения. Сообщения Telegram при этом приходят
  как обычно. Если нужны проверки и во сне, включите **keep_cpu_awake**, но расход
  батареи заметно вырастет. На зарядке телефон в глубокий сон не уходит.

## Ограничения

- Если в Telegram или Mattermost на экране открыт **именно этот чат/канал**, мессенджер
  не показывает уведомление, и алерта не будет (сообщение вы и так видите).
- Работает только то, что мессенджер показывает в уведомлении. Очень длинные сообщения
  обычно приходят целиком, но паттерны, которые ищут текст в самом конце огромного
  сообщения, стоит проверить на реальных алертах.
- Чат/канал определяется по названию. Если его переименуют, обновите название в настройках.
- Корпоративные сборки Mattermost иногда имеют своё имя пакета. Если пункт «Mattermost
  установлен» остаётся ❌, допишите пакет в «Настройки» → «Дополнительно».

## Обновление приложения

Поменяли код? Подключите телефон и снова нажмите **▶ Run** в Android Studio.
Настройки приложения при этом сохранятся.

## Сборка релиза и ключ подписи

Релизный APK подписывается ключом, который лежит **вне репозитория**:

```
Documents\AndroidStudio\
├── AlertWatcher\                ← этот проект
└── keys\
    ├── alertwatcher-release.jks ← ключ
    └── keystore.properties      ← путь к ключу и пароли
```

**Сделайте резервную копию папки `keys`** (например, в менеджер паролей или на флешку).
Без этого ключа новую версию нельзя будет поставить поверх старой: придётся удалять
приложение и настраивать заново. В Git ключ не попадает (`.gitignore`).

Собрать релиз:
1. Поднимите `versionCode` (на 1) и `versionName` в `app/build.gradle.kts`.
2. В терминале Android Studio (вкладка **Terminal** внизу) выполните `.\gradlew assembleRelease`.
3. Готовый файл: `app\build\outputs\apk\release\app-release.apk`.

Если папки `keys` нет (проект склонирован на другой компьютер), debug-сборка
подписывается стандартным отладочным ключом, а release собирается неподписанным.

## Если что-то не работает

- Вкладка **«Журнал»**: там видно, какие сообщения пришли из отслеживаемого чата, какой
  паттерн сработал или почему сообщение пропущено, а также проблемы со связью.
  Кнопка «Копировать» копирует журнал целиком.
- «Доступ к уведомлениям» выдан, а статус всё равно ❌: выключите и снова включите
  доступ в настройках Android или перезагрузите телефон.
- Сообщения из чата не появляются в журнале: проверьте шаги 5/5а и что название
  совпадает с «Замеченными».

## Структура проекта

```
app/src/main/java/com/alertwatcher/
├── App.kt                         — запуск приложения, каналы уведомлений
├── AppLog.kt                      — журнал (вкладка «Журнал», файл log.txt)
├── AppState.kt                    — вкл/выкл, замеченные чаты и каналы
├── config/
│   ├── AppConfig.kt               — настройки, формат JSON (совместим с config.json)
│   ├── AlertMatcher.kt            — проверка ignore_patterns / alert_patterns
│   └── ConfigStore.kt             — хранение настроек
├── notify/
│   ├── TelegramNotificationListener.kt — читает уведомления Telegram и Mattermost
│   ├── MessageNotificationParser.kt    — достаёт чат/канал и тексты сообщений
```
